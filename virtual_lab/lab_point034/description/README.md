# lab_point034

Virtual lab du sampling point Point034 : le laboratoire, le dossier du point et son nettoyage, décrits par `lab.yaml` (dossier `description/`). La commande suivante écrit `data/processed_data/Point034/`, que lisent les twins :

```bash
molonari-twin lab build MOLONARI-TWIN/virtual_lab/lab_point034/description --point Point034
```
